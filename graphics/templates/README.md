# Graphics templates

Approved HyperFrames graphics, one folder per look (e.g. `red-arrow-edges/`, `offer-card/`,
`end-card/`). Each folder is a working HyperFrames project plus a `meta.md` with: what it's for, the
editable bits (text, colours, timing), and the ad it first ran in.

Empty for now: a graphic lands here only after Salam approves it in a real ad.
